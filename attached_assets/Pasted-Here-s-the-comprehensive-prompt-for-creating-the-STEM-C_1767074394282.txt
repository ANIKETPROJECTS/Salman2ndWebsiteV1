Here's the comprehensive prompt for creating the STEM Club website:

---

**Create a comprehensive JSSIS F1 STEM Club website with an integrated web application for competition management. The website should have a modern, playful, student-friendly design with RED and WHITE as the primary color scheme (graphs and charts can use additional colors for clarity). The UI should be visually rich with images, animations, and an engaging interface suitable for school students.**

## **COLOR SCHEME & DESIGN THEME:**
- **Primary colors:** RED (#EF4444 or #DC2626) and WHITE (#FFFFFF)
- Use red for headers, buttons, accents, and key elements
- White backgrounds with red accents
- Secondary colors allowed for graphs, charts, status indicators (green for complete, yellow for pending, blue for info, orange for warnings)
- **Playful & Energetic Design:** Fun animations, engaging visuals, dynamic layouts
- **Image-Heavy Interface:** Large hero images, photo galleries, competition images throughout
- **Student-Friendly:** Colorful, interactive, easy to understand, gamification elements
- Include racing-themed graphics, F1 car illustrations, trophy icons, speed elements
- Use rounded corners, card shadows, gradient effects, hover animations
- Incorporate motion graphics, loading animations, celebration effects
